Load this compact index by default. Do not preload every stable document.

- Service install, health, rollback, logs, IM, and local operations: `docs/LOCAL_RUNTIME.md`

- Trellis direction or task governance only: `.trellis/agents/AGENTS.md`, `.trellis/spec/local-single-machine-mvp.md`, `.trellis/decisions.md`

Read on demand:

1. Select one route from the task intent.
2. Search headings or identifiers first with `rg`.
3. Read only the matching section and cited refs.
4. Load raw state, episodes, logs, SOPs, or skill bodies only when selected evidence requires them.
5. Keep current goal, working checkpoint, and verification evidence hotter than history.

Raw logs and long documents are evidence stores, not resident prompt context.
