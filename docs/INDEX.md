# Documentation Router

After `README.md` and `docs/CURRENT_DIRECTION.md`, load this compact index.
The following are the remaining default documentation inputs; do not preload
long documents.

- Default architecture and planning direction: `docs/CURRENT_DIRECTION.md`
- Stable identity and self-modification stance: `core/soul.md`
- Memory policy and layer ownership: `core/memory.md`
- Current resident pointers: `memory/index.md`
- Shared vocabulary: `CONTEXT.md`
- Implemented facts: source, tests, and verified runtime evidence

Long documents, dated records, and frozen archives are evidence stores, not
route entries. A concrete implementation task may explicitly select the one
needed document or record by its subject or identifier.

Read on demand:

1. For a concrete implementation task, select one evidence source by task
   scope.
2. Search headings or identifiers first with `rg`.
3. Read only the matching section and cited refs.
4. Load raw state, episodes, logs, SOPs, or skill bodies only when selected evidence requires them.
5. Keep current goal, working checkpoint, and verification evidence hotter than history.

Raw logs and long documents are evidence stores, not resident prompt context.
